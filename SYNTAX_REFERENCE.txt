# COMPREHENSIVE SKRIPT LANGUAGE SYNTAX GUIDE

## 1. BASIC SYNTAX RULES

### Comments
- Single-line: `# this is a comment`
- Comments extend to end of line

### Indentation
- Indentation is REQUIRED for block structures
- Indentation level indicates nesting
- Typically 4 spaces or 1 tab per level

### Case Sensitivity
- Skript is case-insensitive for keywords and identifiers
- String values ARE case-sensitive

---

## 2. TOP-LEVEL SECTIONS

### Options Section
```
options:
    prefix: &7[MyScript]
    permission message: &cNo permission!
    command path: true
```

Keywords: `prefix`, `permission message`, `command path`, etc.

### Command Definitions
```
command /name <arg>:
    description: What this does
    usage: /name <arg>
    permission: permission.node
    permission message: Custom message
    trigger:
        # code here
```

### Event Handlers
```
on [event modifier] [event type]:
    # code here
```

Examples: `on player join`, `on damage of player`, `on right click on block`

### Function Definitions
```
function name(param: type, param2: type) :: return_type:
    return value
```

---

## 3. VARIABLES

### Global Variables
- Format: {variable_name}
- Persist across script reloads
- Can be indexed: {variable::%player%::key}

### Local Variables
- Format: {_variable_name} (underscore prefix)
- Only exist within current event/function
- Limited scope

### Variable Declaration and Usage
```
set {var} to value
add value to {var}
remove value from {var}
delete {var}
```

---

## 4. CONTROL FLOW STRUCTURES

### If/Else
```
if condition:
    # code
else if condition:
    # code
else:
    # code
```

### Loop
```
loop all players:
    message "Hi %loop-value%"

loop 10 times:
    message "Count"

loop all blocks in region:
    set loop-block to diamond
```

### While Loop
```
while condition:
    # code
```

### Stop/Continue
```
stop
stop (entity)
loop-continue
```

---

## 5. EXPRESSIONS AND OPERATORS

### Arithmetic Operators
- Addition: +
- Subtraction: -
- Multiplication: *
- Division: /
- Modulo: %
- Power: ^

### Comparison Operators
- Equals: = or ==
- Not equals: != or is not
- Less than: <
- Greater than: >
- Less/equal: <=
- Greater/equal: >=

### Logical Operators
- And: and
- Or: or
- Not: not

### String Operators
- Concatenation: %value% (interpolation in strings)
- Regex match: matches or match

### Comparison Keywords
- is / is not
- is a / is an
- contains
- in / not in

### Assignment Operators
- Set: set var to value
- Add: add value to var
- Remove: remove value from var
- Delete: delete var
- Subtract: subtract value from var
- Multiply: multiply var by value
- Divide: divide var by value

---

## 6. COMMON STATEMENTS

### Messages
```
message "Text"
send "Text" to player
broadcast "Text"
```

### Player Actions
```
give player diamond
remove diamond from player
teleport player to location
```

### Events
```
cancel event
cancel [event type]
```

### Timing
```
wait 1 second
wait 10 ticks
```

---

## 7. TYPES (Type Syntax)

Skript supports various types that can appear in type declarations:
- player
- entity
- block
- item
- location
- number
- string
- text
- boolean
- date
- time span
- world
- inventory
- list
- Custom types

Type declarations appear with :: syntax:
```
function name(param: player) :: number:
    return 5
```

---

## 8. STRING LITERALS

### Quoted Strings
- Single or double quotes: "text" or 'text'
- Supports color codes: &7, &b, &c, etc.

### String Interpolation
- Use %expression% inside strings
- Examples:
  "%player%" -> player name
  "%arg 1%" -> argument
  "%{variable}%" -> variable value

---

## 9. LITERALS

### Numbers
- Integer: 5, 123, -42
- Decimal: 5.5, 3.14, -1.2

### Booleans
- true / false
- yes / no
- on / off

### Time Spans
- 1 second, 5 minutes, 1 hour, 1 tick
- Aliases: sec, min, hr

### Colors
- Using & codes: &a (green), &c (red), &b (blue)

---

## 10. SPECIAL KEYWORDS AND EFFECTS

### Common Effects (Actions)
- set - set variable
- add - add to variable/inventory
- remove - remove from variable/inventory
- delete - delete variable
- message - send message
- send - send message
- broadcast - broadcast to all players
- give - give item
- take - take item
- teleport - teleport entity
- wait - wait time
- cancel - cancel event
- stop - stop execution
- return - return from function
- make - create/set
- shoot - shoot projectile
- spawn - spawn entity
- heal - heal entity

### Event Modifiers
- on first - first time only
- on every - every occurrence

### Comparisons
- contains
- matches / match
- is in / not in

---

## 11. ARGUMENT SYNTAX

### Command Arguments
- Format in definition: <arg> or <type: arg>
- Access in trigger: arg 1, arg 2, argument 1, etc.
- Optional args: [optional]
- Remaining text: <...>

### Event Arguments
- player - the player from event
- victim - damage victim
- attacker - damage attacker
- clicked entity - clicked entity
- clicked block - clicked block
- event - the event itself
- Custom variables as needed

---

## 12. OPERATORS AND PRECEDENCE

### Order (highest to lowest)
1. Parentheses: ()
2. Exponent: ^
3. Multiplication/Division: *, /, %
4. Addition/Subtraction: +, -
5. Comparison: <, >, <=, >=, ==, !=
6. Logical NOT: not
7. Logical AND: and
8. Logical OR: or

---

## 13. SPECIAL VARIABLES

### Built-in Variables
- {player} - current player
- {attacker} - attacker in damage event
- {victim} - victim in damage event
- {block} - clicked/affected block
- {event-trigger-item} - held item in event
- loop-value / loop-player / loop-block - loop iterator
- arg or argument - command arguments

---

## 14. DIRECTIVES/PRAGMAS

Some scripts may have directives at the top:
```
#@require 2.5
#disable variable case override
#disable variable starting with digit
```

---

## 15. ADVANCED FEATURES

### List Variables with Indices
```
{list::%player%::*} - all elements
{list::%player%::1} - specific index
```

### Regex/Pattern Matching
```
if player matches "Notch|Herobrine":
    # code
```

### Custom Functions
```
function my_function(arg: type) :: return_type:
    # code with parameters
    return value
```

### Predicates/Conditions
```
if player is online:
    # only runs if player is online
```

---

## 16. EXAMPLE CODE STRUCTURE

```
# Header comments
# Lines that may document the script

options:
    # Global configuration

# Function definitions
function my_func(param: type) :: type:
    return param

# Command definitions
command /cmd:
    trigger:
        # statements

# Event handlers
on event:
    # statements
```
